# NumPy Basics - Arrays & Operations

A beginner-friendly collection of Python programs covering the fundamentals of **NumPy arrays and numerical operations**.

This section introduces `ndarray` creation, indexing, slicing, array shape, reshaping, arithmetic operations, broadcasting, comparisons, and vectorized operations.

The programs are arranged in a simple learning order, starting with basic array creation and gradually moving toward concepts commonly used in **Data Science and Machine Learning**.

## 📚 Programs Overview

### 01. Create Array

**File:** `01_create_array.py`  
**Learn:** NumPy `ndarray` creation  
**Practice:** Create and display a NumPy array.

### 02. Array Indexing

**File:** `02_array_indexing.py`  
**Learn:** Array indexing  
**Practice:** Access individual elements using positive and negative indexes.

### 03. Array Slicing

**File:** `03_array_slicing.py`  
**Learn:** Array slicing  
**Practice:** Extract a specific range of elements from an array.

### 04. Array Shape

**File:** `04_array_shape.py`  
**Learn:** Array dimensions and `.shape`  
**Practice:** Find the number of rows and columns in a 2D array.

### 05. Array Reshape

**File:** `05_array_reshape.py`  
**Learn:** `.reshape()`  
**Practice:** Convert a one-dimensional array into a 2D array.

### 06. Array Arithmetic

**File:** `06_array_arithmetic.py`  
**Learn:** Element-wise arithmetic operations  
**Practice:** Perform addition, subtraction, multiplication, and division on arrays.

### 07. Array Comparison

**File:** `07_array_comparison.py`  
**Learn:** Element-wise comparison  
**Practice:** Compare array elements using conditions such as `>`, `<`, and `==`.

### 08. Broadcasting

**File:** `08_broadcasting.py`  
**Learn:** NumPy broadcasting  
**Practice:** Perform operations between an array and a single value without using loops.

### 09. Vectorized Operations

**File:** `09_vectorized_operations.py`  
**Learn:** Vectorization  
**Practice:** Perform operations on an entire array without explicitly writing a loop.

### 10. Loop vs Vectorization

**File:** `10_loop_vs_vectorization.py`  
**Learn:** Loops vs NumPy vectorized operations  
**Practice:** Perform the same operation using a Python loop and NumPy vectorization.

### 11. Array Sum & Average

**File:** `11_array_sum_average.py`  
**Learn:** NumPy aggregation functions  
**Practice:** Calculate the sum and average using `np.sum()` and `np.mean()`.

### 12. Minimum & Maximum

**File:** `12_min_max_array.py`  
**Learn:** `np.min()` and `np.max()`  
**Practice:** Find the minimum and maximum values from an array.

## 🧠 Concepts Covered
