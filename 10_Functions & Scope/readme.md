# Functions & Scope – Python

A beginner-friendly collection of Python programs covering **functions, parameters, return values, default arguments, `*args`, `**kwargs`, and variable scope**.

The programs are arranged in a simple learning order, starting with basic function creation and gradually moving toward flexible arguments and scope concepts.

## 📚 Programs Overview

### 01. Simple Function

**File:** `01_simple_function.py`
**Learn:** Creating and calling a function using `def`
**Practice:** Define a simple function and execute it.

### 02. Function Parameters

**File:** `02_function_parameters.py`
**Learn:** Parameters and arguments
**Practice:** Pass values to a function and perform calculations.

### 03. Function Return

**File:** `03_function_return.py`
**Learn:** `return` statement
**Practice:** Return a calculated value from a function.

### 04. Default Arguments

**File:** `04_default_arguments.py`
**Learn:** Default parameter values
**Practice:** Use a default value when an argument is not provided.

### 05. Rectangle Area

**File:** `05_rectangle_area.py`
**Learn:** Parameters and return values
**Practice:** Create a function to calculate the area of a rectangle.

### 06. `*args`

**File:** `06_args.py`
**Learn:** Variable-length positional arguments
**Practice:** Accept multiple numbers and calculate their sum.

### 07. `**kwargs`

**File:** `07_kwargs.py`
**Learn:** Variable-length keyword arguments
**Practice:** Accept and display multiple key-value arguments.

### 08. Local Scope

**File:** `08_local_scope.py`
**Learn:** Local variables
**Practice:** Create and access a variable inside a function.

### 09. Global Scope

**File:** `09_global_scope.py`
**Learn:** Global variables
**Practice:** Access a global variable from inside a function.

### 10. Local vs Global Scope

**File:** `10_local_vs_global.py`
**Learn:** Difference between local and global variables
**Practice:** Understand how Python handles variables with the same name in different scopes.

### 11. Find Maximum

**File:** `11_find_max.py`
**Learn:** Functions with multiple parameters and return values
**Practice:** Find the largest of two numbers using a function.

### 12. `*args` & `**kwargs`

**File:** `12_args_kwargs.py`
**Learn:** Combining positional and keyword arguments
**Practice:** Work with flexible function arguments.

Functions are an important part of Python programming because they help you:

* ♻️ Reuse code
* 🧹 Reduce code repetition
* 📖 Improve readability
* 🛠️ Make programs easier to maintain
* 🧪 Make code easier to test
* 📦 Organize large programs into smaller components

## 📌 Key Example

```python
def add(a, b):
    return a + b


result = add(10, 20)
print(result)
```

**Output:**

```text
30
```

This simple example demonstrates how a function can accept parameters, perform an operation, and return a result.
