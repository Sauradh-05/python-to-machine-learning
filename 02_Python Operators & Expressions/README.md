# Python Operators & Expressions

A beginner-friendly collection of Python programs focused on **arithmetic operations, mathematical formulas, comparison operators, logical conditions, and practical calculations**.

---

## 📚 Programs Overview

### 01. Calculator

**File:** `01_Calculator.py`  
**Learn:** Arithmetic Operators  
**Practice:** Perform addition, subtraction, multiplication, division, and other basic calculations.

### 02. Area & Perimeter

**File:** `02_Area_Perimeter.py`  
**Learn:** Arithmetic Expressions & Formulas  
**Practice:** Calculate the area and perimeter of shapes using mathematical formulas.

### 03. Simple Interest

**File:** `03_Simple_Interest.py`  
**Learn:** Mathematical Expressions  
**Practice:** Calculate simple interest using principal, rate, and time.

### 04. Average

**File:** `04_Average.py`  
**Learn:** Arithmetic Operators  
**Practice:** Calculate the average of multiple numbers.

### 05. Even or Odd

**File:** `05_Even_Odd.py`  
**Learn:** Modulus Operator `%`  
**Practice:** Check whether a number is even or odd using the modulus operator.

### 06. Seconds Conversion

**File:** `06_Seconds_Convert.py`  
**Learn:** Division & Modulus  
**Practice:** Convert total seconds into hours, minutes, and remaining seconds.

### 07. Days Conversion

**File:** `07_Days_Convert.py`  
**Learn:** Integer Division & Modulus  
**Practice:** Convert a number of days into weeks and remaining days.

### 08. Compare Numbers

**File:** `08_Compare_Numbers.py`  
**Learn:** Comparison Operators  
**Practice:** Compare numbers using `>`, `<`, `>=`, `<=`, `==`, and `!=`.

### 09. Age Check

**File:** `09_Age_Check.py`  
**Learn:** Comparison & Logical Operators  
**Practice:** Check a person's age against a given condition and display the result.

### 10. Login

**File:** `10_Login.py`  
**Learn:** Comparison & Logical Operators  
**Practice:** Create a simple login system by checking username and password conditions.

### 11. Bill Calculator

**File:** `11_Bill_Calc.py`  
**Learn:** Arithmetic & Expressions  
**Practice:** Calculate a bill using item prices, quantities, and basic arithmetic.

## 🎯 Learning Objectives

After completing these programs, you should be able to:

- Understand Python operators and expressions.
- Use arithmetic operators for calculations.
- Apply mathematical formulas in Python.
- Use the modulus `%` operator.
- Understand comparison operators.
- Use logical operators in simple conditions.
- Work with division and remainders.
- Build simple real-world calculation programs.
- Combine multiple operators in expressions.

## 🧠 Operators Covered

### Arithmetic Operators

```text
+    Addition
-    Subtraction
*    Multiplication
/    Division
%    Modulus
//   Floor Division
**   Exponentiation
```

### Comparison Operators

```text
>    Greater than
<    Less than
>=   Greater than or equal to
<=   Less than or equal to
==   Equal to
!=   Not equal to
```

### Logical Operators

```text
and
or
not
```

## ▶️ How to Run

Make sure Python is installed on your system.

Open the folder in your terminal and run any program:

```bash
python 01_Calculator.py
```

For example:

```bash
python 11_Bill_Calc.py
```

You can also run these programs using **VS Code**, **PyCharm**, or another Python-compatible editor.
