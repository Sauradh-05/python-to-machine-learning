# Pandas Basics - Series & DataFrames

This repository contains beginner-friendly Python programs to learn the fundamentals of **Pandas**, a popular library for data analysis and manipulation.

The programs are arranged in a simple learning order, starting with Series and DataFrames and progressing to dataset exploration, reading CSV/Excel files, selecting columns, and filtering rows.

## 📚 Programs Overview

### 1. Create a Series
- **File:** `01_create_series.py`
- **Learn:** Create a Pandas Series and access its elements.

### 2. Create a DataFrame
- **File:** `02_create_dataframe.py`
- **Learn:** Create a DataFrame using a dictionary.

### 3. DataFrame from a List
- **File:** `03_dataframe_from_list.py`
- **Learn:** Convert list-based data into a structured DataFrame.

### 4. DataFrame Head
- **File:** `04_dataframe_head.py`
- **Learn:** Display the first few rows using `.head()`.

### 5. DataFrame Info
- **File:** `05_dataframe_info.py`
- **Learn:** Explore column names, data types, and non-null counts using `.info()`.

### 6. DataFrame Describe
- **File:** `06_dataframe_describe.py`
- **Learn:** Generate statistical summaries using `.describe()`.

### 7. Read CSV
- **File:** `07_read_csv.py`
- **Learn:** Import data from CSV files using `pd.read_csv()`.

### 8. Read Excel
- **File:** `08_read_excel.py`
- **Learn:** Import Excel data using `pd.read_excel()`.

### 9. Select Columns
- **File:** `09_select_columns.py`
- **Learn:** Select individual or multiple DataFrame columns.

### 10. Filter DataFrame
- **File:** `10_filter_dataframe.py`
- **Learn:** Filter rows using conditions.

## 🛠️ Requirements

- Python 3.x
- Pandas
- OpenPyXL (for `.xlsx` files)

## ⚙️ Installation

Install the required libraries using:

```bash
pip install pandas openpyxl
```

## ▶️ How to Run

Run any Python program from your terminal:

```bash
python 01_create_series.py
```

For CSV and Excel programs, place the corresponding data files in the same directory as the Python scripts, or provide the correct file path.

1. Create a Product DataFrame with five products.

3. Inspect dataset information using `.info()`.

## 🚀 Learning Goals

- Understand Series and DataFrames.
- Create structured datasets.
- Read CSV and Excel files.
- Explore datasets using `.head()`, `.info()`, and `.describe()`.
- Select columns and filter rows.
- Build a foundation for data cleaning and Machine Learning.
