# Pandas - GroupBy, Merge & Pivot Tables

This project focuses on important Pandas concepts used to group, combine, aggregate, and summarize datasets. It includes practical Python programs with solutions to strengthen data analysis skills.

The programs are arranged in a simple learning order, from basic grouping operations to combining multiple techniques for sales analysis.

## 📚 Programs Overview

### 1. GroupBy Sales

**File:** `01_groupby_sales.py`

**Learn:** Group data using `groupby()` and calculate total sales for each employee using `sum()`.

**Practice:** Find the total sales generated by each employee.

### 2. GroupBy Multiple Columns

**File:** `02_groupby_multiple_columns.py`

**Learn:** Group data using multiple columns to analyze information across different categories.

**Practice:** Calculate total sales for each department in each region.

### 3. Aggregation Functions

**File:** `03_aggregation_functions.py`

**Learn:** Use `agg()` with `sum()`, `mean()`, `min()`, `max()`, and `count()` to generate summary statistics.

**Practice:** Calculate sales statistics for each department.

### 4. Merge DataFrames

**File:** `04_merge_dataframes.py`

**Learn:** Combine two DataFrames using `merge()` and understand how a left join preserves all records from the left DataFrame.

**Practice:** Combine employee details with department information using `Employee_ID`.

### 5. Join DataFrames

**File:** `05_join_dataframes.py`

**Learn:** Use `join()` to combine DataFrames based on their indexes.

**Practice:** Combine employee details with performance scores and ratings.

### 6. Pivot Tables

**File:** `06_pivot_table.py`

**Learn:** Create pivot tables using `pivot_table()` to summarize data across rows and columns.

**Practice:** Calculate total sales for each employee across different regions.

### 7. Sales Analysis

**File:** `07_sales_analysis.py`

**Learn:** Combine calculated columns, `groupby()`, aggregation functions, and pivot tables for practical data analysis.

**Practice:** Calculate product revenue, summarize revenue by region, and compare product revenue across regions.

## 🛠️ Requirements

- Python 3.x
- Pandas

Install Pandas using:

```bash
pip install pandas
```

## ▶️ How to Run

1. Clone or download this repository.
2. Open the project folder in your code editor.
3. Run any Python file using the command below:

```bash
python 01_groupby_sales.py
```

Replace the filename with the program you want to execute.

## 🎯 Learning Objectives

After completing these programs, you should be able to:

- Group datasets using one or multiple columns.
- Perform aggregations and calculate summary statistics.
- Merge DataFrames using common columns.
- Join DataFrames using indexes.
- Create pivot tables for comparing categories.
- Calculate revenue and analyze sales performance.
- Combine Pandas operations to solve practical data analysis problems.

## 💡 Additional Practice

- Identify the employee with the highest total sales.
- Group sales by department, region, and employee.
- Experiment with inner, left, right, and outer merges.
- Create pivot tables using average sales instead of total sales.
- Calculate each product's percentage contribution to total revenue.
