# Type Casting & Input/Output – Python

A beginner-friendly collection of Python practice programs focused on **user input, output formatting, type casting, calculations, conversions, and practical problem-solving**.

The programs are arranged in a simple learning order so that each exercise builds on the concepts introduced earlier.

---

## 📚 Programs Overview

### 01. Arithmetic Operations
**File:** `01_Arithmetic.py`  
**Learn:** Input, Type Casting & Arithmetic Operators  
**Practice:** Take numbers as input and perform basic arithmetic operations such as addition, subtraction, multiplication, and division.

### 02. Marks & Average
**File:** `02_Marks_Average.py`  
**Learn:** Input, Numbers & Arithmetic  
**Practice:** Take marks as input and calculate the total and average of the given marks.

### 03. Kilometers to Miles
**File:** `03_Km_to_Miles.py`

### 04. f-String
**File:** `04_F_String.py`

**Practice:** Take user information and display it clearly using Python f-strings.

### 05. Number Conversion
**File:** `05_Num_Convert.py`

**Practice:** Convert numbers between different data types such as `int` and `float`.

### 06. GST Calculator
**File:** `06_GST_Calc.py`

## 🧠 Concepts Covered

### Input

```python
name = input("Enter your name: ")
```

### Type Casting

```python
age = int(input("Enter your age: "))
price = float(input("Enter the price: "))
```

### Output

```python
print("Your age is:", age)
```

### f-String

```python
print(f"My name is {name} and I am {age} years old.")
```

### Common Type Conversion Functions

```text
int()     → Convert to integer
float()   → Convert to decimal number
str()     → Convert to string
```

### Useful Operators

```text
+     Addition
-     Subtraction
*     Multiplication
/     Division
//    Floor Division
%     Modulus
```
