# Data Visualization - Matplotlib Essentials

This repository contains beginner-friendly Python programs to learn data visualization using Matplotlib.

The programs cover different types of charts, including line plots, bar plots, scatter plots, histograms, and subplots.

The goal is to understand how to visualize data and present information in a clear and meaningful way.

## 📚 Concepts Covered

1. **Line Plot** – Visualizing trends and changes over time.
2. **Bar Plot** – Comparing values across different categories.
3. **Scatter Plot** – Understanding relationships between two variables.
4. **Histogram** – Visualizing the distribution of numerical data.
5. **Subplots** – Displaying multiple charts in a single figure.
6. **Titles & Labels** – Customizing charts with titles, axis labels, and grid lines.

## 💻 Programs Overview

### 1. Line Plot
- **File:** `01_line_plot.py`
- **Learn:** Create line charts using `plt.plot()`.
- **Practice:** Visualize monthly sales trends.

### 2. Bar Plot
- **File:** `02_bar_plot.py`
- **Learn:** Create bar charts using `plt.bar()`.
- **Practice:** Compare student marks across subjects.

### 3. Scatter Plot
- **File:** `03_scatter_plot.py`
- **Learn:** Visualize relationships using `plt.scatter()`.
- **Practice:** Analyze study hours versus exam scores.

### 4. Histogram
- **File:** `04_histogram.py`
- **Learn:** Understand data distribution using `plt.hist()`.
- **Practice:** Visualize the distribution of student marks.

### 5. Subplots
- **File:** `05_subplots.py`
- **Learn:** Create multiple visualizations using `plt.subplots()`.
- **Practice:** Build a simple visualization dashboard.

3. Install the required library.

