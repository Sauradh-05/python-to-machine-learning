# 🐍 Python Conditional Statements - Practice Programs

This folder contains beginner-friendly Python programs based on **conditional statements**.  
Each program focuses on a specific real-world problem and helps build a strong understanding of `if`, `elif`, and `else`.

---

## 📁 Program Overview

### 01 - Positive & Negative

**File:** `01_Positive_Negative`  
**Description:** Checks whether a given number is positive, negative, or zero.

### 02 - Even & Odd

**File:** `02_Even_Odd`  
**Description:** Checks whether a given number is even or odd.

### 03 - Voting Check

**File:** `03_Voting_Check`  
**Description:** Checks whether a person is eligible to vote based on their age.

### 04 - Greatest Number

**File:** `04_Greatest_Num`  
**Description:** Compares numbers and finds the greatest number.

### 05 - Grade Calculator

**File:** `05_Grade_Calc`  
**Description:** Calculates a student's grade based on their marks.

### 06 - Leap Year

**File:** `06_Leap_Year`  
**Description:** Checks whether a given year is a leap year.

### 07 - Login Check

**File:** `07_Login`  
**Description:** Validates a username and password using conditional statements.

### 08 - Calculator

**File:** `08_Calculator`  
**Description:** Performs basic arithmetic operations based on the selected operator.

---

## 🎯 Learning Objectives

By completing these programs, you will practice:

- Using `if`, `elif`, and `else`
- Working with comparison operators
- Using logical operators
- Taking user input
- Type conversion
- Making decisions based on conditions
- Applying conditional logic to real-world problems
- Building simple interactive Python programs

---

## 🛠️ Concepts Covered

**Conditional Statements**  
`if` → `elif` → `else`

**Comparison Operators**  
`>`, `<`, `>=`, `<=`, `==`, `!=`

**Logical Operators**  
`and`, `or`, `not`

**Arithmetic Operators**  
`+`, `-`, `*`, `/`, `%`

**User Input**  
`input()`

**Type Conversion**  
`int()`, `float()`



## ▶️ How to Run

Make sure Python is installed on your system.

Run any program using:

```bash
python filename.py
```

For example:

```bash
python 01_Positive_Negative.py
```
