## 🛠️ Concepts Covered

### 🔹 For Loop

Used to repeat a block of code for a specific sequence or range.

### 🔹 While Loop

Used to repeatedly execute code while a condition remains `True`.

### 🔹 Range Function

Used to generate a sequence of numbers for loops.

### 🔹 Break

Stops the execution of a loop immediately.

### 🔹 Continue

Skips the current iteration and moves to the next iteration.

### 🔹 Nested Loops

A loop placed inside another loop, commonly used for patterns and tables.
