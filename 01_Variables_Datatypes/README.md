## 🧠 Concepts Covered

### Variables

Variables are used to store data in Python.

```python
name = "Rahul"
age = 21
height = 5.8
```

### Basic Data Types

```text
int      → Whole numbers
float    → Decimal numbers
str      → Text
bool     → True / False
```

### Input & Output

```python
name = input("Enter your name: ")
print("Hello", name)
```

### Type Casting

```python
age = int(input("Enter your age: "))
price = float(input("Enter price: "))
```

### Arithmetic Operators

```text
+    Addition
-    Subtraction
*    Multiplication
/    Division
%    Modulus
```
