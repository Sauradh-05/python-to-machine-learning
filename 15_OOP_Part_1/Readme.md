# OOP Part 1 – Classes & Objects

This repository contains beginner-friendly Python practice programs covering the fundamentals of Object-Oriented Programming (OOP), focusing on classes and objects.

The programs are arranged in a simple learning order, starting with basic class creation and gradually moving toward practical examples using attributes, methods, constructors, and multiple objects.

## 📚 Programs Overview

1. **Create a Class** – Learn how to define a class and create an object.
2. **Student Details** – Understand attributes, methods, and constructors.
3. **Employee Details** – Work with multiple object attributes.
4. **Rectangle Area** – Perform calculations using class methods.
5. **Circle Area** – Calculate the area using an object's radius.
6. **Book Details** – Store and display book information.
7. **Car Information** – Create multiple objects from one class.
8. **Bank Account** – Practice deposits, withdrawals, and balance management.
9. **Product Details** – Calculate the total price of products.
10. **Mobile Phone** – Represent a mobile phone using a class.
11. **Student Marks** – Calculate average marks using methods.
12. **Simple Calculator** – Perform arithmetic operations using a class.

## 🧠 Concepts Covered

* Classes and objects
* Attributes and methods
* The `__init__()` constructor
* The `self` parameter
* Creating multiple objects
* Instance-specific data
* Returning values from methods
* Basic real-world applications of OOP

## 🎯 Learning Objective

The goal of this practice set is to build a strong foundation in Python OOP before moving on to more advanced concepts such as inheritance, polymorphism, encapsulation, and abstraction.

## 🛠️ Technologies Used
