# Dictionaries in Python 🗂️🐍

A beginner-friendly collection of Python programs covering **dictionaries, key-value pairs, dictionary methods, loops, nested dictionaries, and practical dictionary operations**.

The programs are arranged in a simple learning order, starting with basic dictionary creation and gradually moving toward practical problems.

## 📚 Programs Overview

### 01. Create and Access Dictionary

**File:** `01_create_dictionary.py`
**Learn:** Dictionary creation and accessing values using keys
**Practice:** Store and retrieve student information.

### 02. Add and Update Values

**File:** `02_add_update_dictionary.py`
**Learn:** Adding new key-value pairs and updating existing values
**Practice:** Add a course and update student information.

### 03. Dictionary Methods

**File:** `03_dictionary_methods.py`
**Learn:** `.keys()`, `.values()`, and `.items()`
**Practice:** Access dictionary keys, values, and key-value pairs.

### 04. Loop Through Dictionary

**File:** `04_dictionary_loop.py`
**Learn:** Iterating through dictionaries using loops
**Practice:** Display each key and value.

### 05. Check Key Exists

**File:** `05_check_key.py`
**Learn:** Using the `in` operator with dictionaries
**Practice:** Check whether a specific key exists.

### 06. Remove Dictionary Item

**File:** `06_remove_item.py`
**Learn:** Removing dictionary elements using `.pop()`
**Practice:** Remove a specific student detail.

### 07. Nested Dictionary

**File:** `07_nested_dictionary.py`
**Learn:** Dictionaries inside dictionaries
**Practice:** Store information about multiple students.

### 08. Student Marks

**File:** `08_student_marks.py`
**Learn:** Working with dictionary values
**Practice:** Calculate total and average marks.

### 09. Highest Marks

**File:** `09_highest_marks.py`
**Learn:** Finding the maximum value in a dictionary
**Practice:** Find the subject with the highest marks.

### 10. Character Frequency

**File:** `10_character_frequency.py`
**Learn:** Dictionary-based counting
**Practice:** Count the frequency of characters in a string.

## 🎯 Topics Covered

* Dictionary creation
* Key-value pairs
* Accessing dictionary values
* Adding and updating elements
* Removing elements
* `.keys()`
* `.values()`
* `.items()`
* Dictionary loops
* Checking keys
* Nested dictionaries
* Practical dictionary operations
* Frequency counting

## 💡 Key Takeaways

Dictionaries are one of the most useful data structures in Python because they allow data to be stored and accessed using **meaningful keys**.

They are widely used for working with structured data such as:

* 👨‍🎓 Student records
* 👨‍💼 Employee information
* 🛒 Product details
* 📊 Data analysis
* ⚙️ Configuration data
* 🤖 Machine Learning datasets

## 🛠️ Requirements

* Python 3.x
* Any Python-compatible IDE or code editor
