# Modules, Packages & Virtual Environments - Python

This section focuses on **Modules, Packages, and Virtual Environments** in Python, with practical examples to understand how modules work and how code can be organized and reused efficiently.

The programs are arranged in a simple learning order, starting with creating and importing modules, followed by built-in modules and a mini project.

## 📚 Programs Overview

### 1. Create and Import a Module

**Learn:**
- What is a Python module?
- Creating a custom module
- Importing a module

**Practice:**
Understand how to create a Python module and reuse its functions in another Python file.

---

### 2. Import Specific Functions

**Learn:**
- Using `from ... import`
- Importing specific functions
- Reusing functions from other modules

**Practice:**
Learn how to import and use only the required functions from a custom module.

---

### 3. Module Aliases

**Learn:**
- Using the `as` keyword
- Creating shorter module names
- Accessing module functions through aliases

**Practice:**
Use an alias to import a module and access its functions with a shorter name.

---

### 4. Built-in Modules

**Learn:**
- Python standard library
- `random` module
- `datetime` module

**Practice:**
Generate random numbers and display the current date using Python's built-in modules.

---

### 5. Student Utilities Mini Project

**Learn:**
- Creating reusable functions
- Importing custom modules
- Working with lists and functions
- Organizing program logic

**Practice:**
Build a student utility program that calculates average marks and determines whether a student has passed or failed.

## 🎯 Key Concepts Covered

The goal of this section is to build a strong understanding of Python modules and code reusability, creating a foundation for developing organized and maintainable Python applications and future Machine Learning projects.
